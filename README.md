# FundStack Server

## Description:
FundStack is a web based microloan request, review and approval management system. Many small financial organizations, NGOs and microloan providers struggle to maintain loan applications, verification, approvals and repayment in one streamlined system.

  ---
  **Live Server:** [https://fund-stack-server.vercel.app]
## Purpose:

- Loan application submission
- User verification
- Loan Approval workflow
- payment tracking
- secure authentication and authorization
- admin and borrower management
---
## Key Features
- User authentication and authorization using firebase token
- Role-based access system (Admin & Borrower)
- Loan application management
- Loan review and approval workflow
- Repayment tracking system
- Pagination, Search & Filter endpoints
- Protected API routes
- Admin dashboard functionalities
- stripe (payment methods)
